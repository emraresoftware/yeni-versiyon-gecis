### Kritik platform bulguları

1. **Tenant izolasyon query filter eksik:**  
   `SECURITY_AUTHORIZATION.md` ve `ENTITY_STANDARDLARI.md` `_tenantProvider.TenantId` ile global filter gerektiriyor.  
   Mevcut EF config’lerde yalnızca `!IsDeleted` filter var; **`TenantId == currentTenant` filter uygulanmıyor**.

2. **Eksik EF configuration:** `UserRole`, `RolePermission`, `AuditLog` için `IEntityTypeConfiguration` yok (DbSet tanımlı, config eksik).

3. **Permission global modeli:** `TenantId = Guid.Empty` — strateji dokümante edilmeli; aksi halde tenant filter eklendiğinde global permission’lar kaybolur.

4. **Rol adlandırma uyumsuzluğu:**  
   - `SECURITY_AUTHORIZATION.md`: `SystemAdmin`, `TenantAdmin`, …  
   - `Role.Create` regex: PascalCase tek kelime (`^[A-Z][a-zA-Z0-9]*$`) — `SystemAdmin` uyumlu, ancak `CRM.Account.Read` gibi permission kodları role code olarak kullanılamaz (doğru ayrım).

5. **`RoleAssignedDomainEvent`** tanımlı (`RoleEvents.cs`) fakat `UserRole.Create` event raise etmiyor — event matrix tutarsızlığı.

6. **`ITenantProvider`, `ICurrentUser`, `IDateTimeProvider`** arayüzleri Domain’de; Infrastructure implementasyonu yok → Persistence interceptor’ları DI olmadan çalıştırılamaz.

## Suggestions

1. **Tenant filter:** `EmareDbContext.OnModelCreating` içinde `ITenantProvider` enjekte edilerek tüm `IHasTenant` entity’lere `HasQueryFilter(e => e.TenantId == _tenantProvider.TenantId && !e.IsDeleted)` uygulanmalı; `Permission` ve `Tenant` için istisna stratejisi ADR ile sabitlenmeli.

2. **Aggregate modeli:** `Tenant`, `ApplicationUser`, `Role` vb. ya `AggregateRoot`’a yükseltilmeli ya da `IRepository` kısıtı `BaseAuditableEntity` / custom marker interface ile güncellenmeli.

3. **Katman tamamlama (Task 004+):** Application’da en az bir örnek Command/Query + validator; Infrastructure’da `ICurrentUser`, `ITenantProvider`, `IDateTimeProvider` implementasyonları; API’de DI wiring ve health endpoint.

4. **Persistence testleri:** InMemory veya Testcontainers PostgreSQL ile interceptor testleri (audit alanları, soft delete, AuditLog immutability).

5. **Doküman hizalama:** `ENTITY_STANDARDLARI.md` audit alan adları güncellenmeli; ADR dosyaları görev brief’indeki path’e (`Yeni versiyon geçiş/docs/adr/`) kopyalanmalı veya index düzeltilmeli.

6. **Shared Kernel sadeleştirme:** `ApiResponse<T>` ve MediatR referansını BuildingBlocks’tan Contracts/Application’a taşımayı değerlendirin.

7. **WeatherForecast template:** `Emare.Platform.API/Program.cs` platform bootstrap ile değiştirilmeli; `DateTime.UtcNow` kullanılmalı veya kaldırılmalı.

8. **Domain event tutarlılığı:** `UserRole.Create` → `RoleAssignedDomainEvent`; `RolePermission.Create` → uygun event eklenmeli.
