# 📊 02_TOKEN_ECONOMICS.md (Token Ekonomisi ve Fayda Modeli)

EAOS platformunun yerel token'ının arz, talep ve ekosistem içi kullanım (utility) standartlarını belirler.

---

## 1. Token Fayda Senaryoları (Utility)
* **İşlem Ücretleri:** Ajanların yürüttüğü otonom iş akışları ve API Gateway çağrıları için ödenen işlem ücretleri.
* **Hizmet Satın Alma:** Eklenti pazarından (Marketplace) alınan üçüncü taraf modüllerin ve eklentilerin lisans ödemeleri.
* **Staking:** Geliştiricilerin pazar yerine güvenli eklenti yayınlayabilmeleri için staking yapma zorunluluğu.

---

## 2. Enflasyon ve Yakım (Burn) Mekanizmaları
* Otonom ajans işlemlerinden alınan işlem ücretlerinin (gas fees) %20'si otomatik olarak yakılarak (burn) ekosistemdeki token arzı dengelenir.
